# مشروع Wuzzuf - منصة التوظيف

مشروع كبير قعدت فيه فترة طويلة بفضل الله، المشروع عبارة عن منصة توظيف متكاملة تربط بين الباحثين عن عمل وأصحاب الشركات. المنصة بتوفر تجربة سلسة للطرفين في عملية البحث عن الوظائف وتقديم الطلبات.

## النظام بيشمل إيه؟ ✅

### 🔐 نظام التسجيل والدخول
- نظام تسجيل دخول آمن
- صلاحيات مختلفة (صاحب شركة، باحث عن عمل، زائر)
- إدارة الملف الشخصي مع إمكانية رفع السيرة الذاتية والصورة الشخصية

### 👥 الملفات الشخصية
- ملفات شخصية قابلة للتخصيص
- رفع وإدارة السيرة الذاتية
- نبذة مختصرة عن الخبرات
- تخصيص الصورة الشخصية

### 💼 إدارة الوظائف
- نظام نشر الوظائف لأصحاب الشركات
- تفاصيل دقيقة للوظائف تشمل:
  - وصف الوظيفة
  - المسؤوليات
  - المؤهلات المطلوبة
  - المميزات
  - الموقع
  - نوع الوظيفة
  - مستوى الخبرة
  - الجنس
  - التصنيف

### 📝 نظام التقديم للوظائف
- عملية تقديم الطلبات
- إرفاق خطاب التقديم
- رفع السيرة الذاتية أثناء التقديم
- متابعة حالة الطلب
- مراحل متعددة للتقديم (الفحص الأولي، إلخ)

### 💬 نظام المحادثة المباشرة
- نظام محادثة بين صاحب الشركة والمرشح
- تكامل مع Pusher للمحادثات المباشرة
- المحادثة متاحة في المراحل المتقدمة من التقديم

### 🔍 البحث والتصفية
- تصفح جميع الوظائف المتاحة
- تصفية حسب الموقع
- تصفية حسب الشركة
- تنظيم حسب التصنيف

## التقنيات المستخدمة
- إطار عمل Laravel
- قاعدة بيانات MySQL
- Pusher للميزات المباشرة
- تخزين الملفات للسير الذاتية والصور
- نظام صلاحيات للتحكم في الوصول

## كيفية البدء

1. نسخ المشروع
2. تثبيت المكتبات: `composer install`
3. إعداد متغيرات البيئة
4. تشغيل الترحيلات: `php artisan migrate`
5. تشغيل السيرفر: `php artisan serve`
